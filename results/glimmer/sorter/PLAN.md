# P37: untrained Glimmer sorts new archive runs

No training. Reuse phase 2's pinned base revision, NF4 with double quantisation and bfloat16 compute, quantisation storage and unquantised load dtype; L4, batch eight, greedy decoding, low reasoning, 512 new tokens, native-assistant-header-v1 parser and first 1,024 OCR characters. The original system/user prompt and enabled five Treasury families are reused directly. No adapter. The existing approved-title check still confirms a family using the page's text. An invalid answer fails visibly; `other` means unsupported. With no OCR layer, the current image classifier remains.

The task cap is **$10 of Modal credits**, separate from earlier Glimmer experiments. `GLIMMER_CAP_USD=10` is the default; the ten-page check uses a tighter $2 cap. Every call uses `load_roles` → Cache → Budget → backend, and the canonical `results/spend_ledger.jsonl`. A cross-process lock serialises the sorter cap check, RPC and ledger write. Cache hits do not spend. Submitted failures retain the full request ceiling rather than silently freeing it. The backend checks Treasury development membership against `split.json` before looking up the private endpoint. References are local provenance, never model input.

The private deployed Modal class is `archivist-glimmer-sorter-p37/GlimmerSorter.infer`. It loads the base once per cold container; minimum zero, maximum one container, two-second idle scale-down, four physical CPUs and 32 GiB RAM, no retries. Each request has a **900-second hard execution timeout and 300-second startup timeout**; allocation waiting is limited to 900 seconds and cancels only this call. No other task's app is stopped. Deployment provisions no warm GPU. No public HTTP endpoint or key is introduced.

At the checked [Modal rates](https://modal.com/pricing), L4 $0.000222/s + four CPUs $0.0000524/s + 32 GiB $0.00007104/s = **$0.00034544/s**. Reserve 900 execution + 300 startup + 17 idle/transport/shutdown seconds = **$0.42040048 maximum per RPC** before a GPU is requested. On success the ledger records measured inference plus the full startup/shutdown allowance, deliberately conservative even when warm; provider billing is reported separately when available. The live check is one ten-page RPC, two native batches (eight and two), plus a $0.10 deployment/storage allowance: **at most $0.52040048**, within its $2 limit. No automatic retry, fallback GPU, precision change, longer OCR or adapter is authorised here.
