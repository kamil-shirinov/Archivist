Each cell is named by its row's printed label and the heading it sits under, as the first read returned them, and by its column heading. The row number is only a hint, and the red box only a locator: where either disagrees, the named row and column win.

Choose Row not on the page when that label can't be found under that heading. It counts as a wrong value for the single read, and for Archivist wherever it accepted the cell.

Choose Column not on this page when the page doesn't print that column heading. Results are given both ways for cells on pages whose layout differs from the template: with those cells left out, and with this choice counted as a wrong value.
